# Projeto Flask - Estudos

Este repositório contém meus estudos iniciais com o framework Flask em Python.

## Objetivo
Aprender o desenvolvimento web utilizando Flask, incluindo:
- Rotas
- Estrutura de projeto
- Templates HTML
- Banco de dados com ORM (Flask-SQLAlchemy)
- Migrações de banco de dados (Flask-Migrate)

## Tecnologias utilizadas
- Python
- Flask
- Flask-SQLAlchemy (ORM)
- Flask-Migrate (controle de versão do banco de dados)
- SQLite

## Como rodar o projeto
1. Clone o repositório
2. Crie e ative um ambiente virtual
3. Instale as dependências: `pip install -r requirements.txt`
4. Aplique as migrações: `flask db upgrade`
5. Rode a aplicação: `flask run`
